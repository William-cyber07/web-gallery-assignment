# Task 2 Brief Report — Ghana Tourist Sites Web Gallery

## Website Researched
The navigation menu style adopted in this project was researched from the
Ghana Tourism Authority website (www.visitghana.com). It features a clean,
horizontal navigation bar with clearly labelled links and a strong accent
colour, which made it simple to reproduce using basic HTML and CSS.

## Menu Style Adopted
A horizontal top navigation menu was adopted, built with an unordered list.
The menu uses a dark blue background (#003366), white bold text, and a gold
(#ffd700) accent border at the bottom. Links are evenly spaced and turn
gold with a lighter blue background when hovered.

## Observations
- The original Task 1 pages had no navigation between pages.
- Lists and tables were unstyled, so headings, borders and backgrounds did not
  look organised.
- The pages worked, but the overall appearance was plain and hard to read.

## Challenges and How I Navigated Them
- **Consistency:** Applying the same menu to four pages required copying the
  same HTML snippet into each page while linking one shared stylesheet.
- **Styling tables:** Moving presentational attributes such as borders into the
  external style.css made the styling cleaner and reusable.
- **Keeping it basic:** Only internal CSS concepts were used (no frameworks or
  templates) as required by the task.

## Navigation
The navigation menu links to the four pages:
- Image Gallery
- Video Gallery
- About
- Contact

## Skills Acquired
Through Task 2, I learned how to use an external CSS file, style headings,
backgrounds, colours, borders, tables, paragraphs and forms, and how to build
a multi-page website navigation menu using HTML lists and links.
